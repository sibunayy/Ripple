# Getting started

## Install
Open the site in Safari on iPad → Share → **Add to Home Screen**. RippleFlow then launches full-screen and works offline. Installed web apps are exempt from Safari's 7-day storage clean-up, so install before doing serious work, and use **Backup** on important projects.

## Make something in ten minutes
1. **New project** (or start from a template). Open **Settings** to set size, frame rate, duration and background colour; presets cover HD, 4K, square, vertical and Lottie sizes.
2. **Draw.** Use the tool palette on the left of the viewer: rectangle, ellipse, polygon, star, line, pen, text. Drag to size, tap for the default. With the pen, tap for corners and drag for smooth curves; tap the first node to close.
3. **Style.** Inspector → Fill / Stroke (solid, linear, radial gradients), Trim paths (draw-on), Repeater.
4. **Animate.** Tap ◷ beside a property → it becomes animated. Scrub the timeline, change the value, keyframes appear in the dope sheet. The **Graph** tab edits easing curves; **Presets** applies ready-made motion (fade, slide, pop, bounce, blur-in, draw-on, loops…).
5. **Compose.** Blend modes, masks (rectangle, ellipse or pen-drawn, keyframable), track mattes, parenting, pre-compose, adjustment layers.
6. **Polish.** Effects tab: blur, glow, drop shadow, noise, distortions, Levels, Curves, 3D LUTs, tint/tritone, vignette… or write a shader. Turn on motion blur per layer and in Settings. Text supports animators (by character, word or line).
7. **Export.** Export → MP4, WebM, GIF, image sequences, stills, Lottie, or a `.ripple` backup. Jobs run in a queue while you keep editing.

## Good to know
- Everything autosaves; **Settings → Earlier versions** restores a previous automatic snapshot.
- Pinch to zoom, two fingers to pan. With the Pencil, resting palms are ignored.
- Numeric fields scrub: drag the small label left/right (Shift = fine).
- **Preview quality: Auto** trades resolution for smooth playback; exports are always full quality. Tap **ƒ** in the viewer for a performance overlay.
- Video plays muted; exports have no audio (not part of v1).
