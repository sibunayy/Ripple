# Keyboard shortcuts

(⌘ is Ctrl on external keyboards for Windows/Linux browsers.)

| Keys | Action |
|---|---|
| `Space` | Play / pause |
| `← / →` | Step one frame (Shift: ten) |
| `Home / End` | Jump to start / end |
| `Alt + ← / →` | Previous / next keyframe |
| `I / O` | Set work-area in / out |
| `K` | Toggle auto-key |
| `M` | Add marker |
| `⌘Z / ⇧⌘Z` | Undo / redo |
| `⌘S` | Save now |
| `⌘D` | Duplicate layer |
| `⌘A` | Select all (unlocked) layers |
| `Shift`+click / drag empty space | Add to selection / marquee select (viewer) |
| `⌘C / ⌘V` | Copy / paste keyframes |
| `⌘⇧ ← / →` | Nudge selected keyframes |
| `Delete` | Delete keyframes, node or layer |
| `V` | Select tool |
| `H` | Hand tool |
| `R · E · Y · S` | Rectangle · Ellipse · Polygon · Star |
| `L` | Line |
| `P` | Pen (Enter finishes, Esc cancels) |
| `T` | Text |
| `Shift while scaling` | Uniform scale |
| `Shift while rotating` | Snap to 15° |
| `Alt while dragging` | Disable snapping |
| `Alt while dragging a handle` | Break node symmetry |
| `?` | This help |
